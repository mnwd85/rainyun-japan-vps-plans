## 限流量还是不限流量：同价不同带宽怎么取舍

两条线路同价，这是选东京节点最需要想清楚的一步。33 元档最典型：限流量版下行 40M，无限流量版下行 10M，带宽差 4 倍；反过来，一个只给 30GB 月流量，一个不计流量。

看你的用途落在哪一边：

- **放网站、博客、接口服务、给国内用户访问**，选极速三网限流量。打开速度取决于带宽，40M 下行和 10M 下行的体验差距很直接，30GB 折合每天 1GB，纯文字站和小接口够用。
- **挂下载、跑定时任务、做数据同步、给多台机器当跳板**，选无限流量。这类用途对瞬时带宽不敏感，但对月流量总额敏感，10M 下行跑满一个月也能跑掉几个 TB。
- **图片多、带视频的站点**：两边都不太够。限流量版的 30GB 撑不了几天，无限流量版的 10M 下行又撑不起并发。这种情况要么加钱上 77 元档的 100M 下行配 80GB 流量，要么考虑大带宽的香港或美国节点。

- 国内平均延迟约 72ms，电信平均 90ms、联通 55ms、移动 71ms
- 港澳台方向平均约 41ms
- 国内节点基本无丢包，海外个别节点偶有轻微波动

联通用户在这台机器上的体验最好，55ms 的平均值已经接近部分香港节点的水平。电信走 CN2 回程，90ms 在同价位日本机房里属于正常偏好的成绩，CN2 的优势主要体现在晚高峰的稳定性上。移动 71ms 中规中矩。

有一条容易被忽略：**IP 非原生**。做流媒体解锁、注册某些对 IP 归属敏感的服务、需要“干净 IP”的场景，这条是硬约束，买之前先确认你的用途能不能接受。测评方也提到海外节点偶有轻微波动，长期跑满带宽的业务要留余量。

CPU 方面，第三方记录东京节点为 AMD 平台，具体型号公开资料没有明确，官网下单页可以看到。磁盘 I/O 1843MB/s 这个数字在 30 元档的机器里算不错，跑数据库和容器不会拖后腿。

## 下单前要确认的五件事

**1. 套餐是否含独立公网 IP。** 雨云不少机型默认 NAT 模式，共用公网 IP，只能开固定数量的端口映射（一般 10～15 个）。NAT 机拿来学 Linux、做内网穿透够用，但不能直接对外提供网站服务。海外独立 IP 是 5 元/个/月，一台机器最多 3 个。东京套餐的默认 IP 形态公开资料没有写清，下单页务必确认。

**2. 月流量的计费方向。** 30GB、50GB、80GB 这些额度是单向还是双向计算，超限后的限速阈值是多少，结算页和帮助文档里都有，比看测评文章准。

**3. 硬盘扩容是另收费的。** 默认 30GB，扩固态按 0.3～0.4 元/GB/月、机械按 0.1 元/GB/月。要跑数据库或者存一堆镜像，这笔钱别漏算。

**4. 日本节点免备案，国内节点不免。** 东京、香港、韩国、德国、美国节点绑定域名对外提供网站服务不需要备案；江苏宿迁、镇江、宁波、湖北十堰这些国内机房必须先备案。这是选日本节点最常见的原因之一。

**5. 需要 macOS 的话，日本装不了。** 目前只有香港 2 区、香港 4 区和湖北十堰支持安装 macOS，东京节点只提供 Linux 和 Windows。
